# SMP Infra

Configs and tooling for a small, invite-only Minecraft survival server for a group of friends.

Nothing fancy: we are trying to keep the server simple, with a few good for us plugins.

## What's here

Some things might be private for now, but we are working on it.

- **server**: Docker Compose setup, Paper config, and backup scripts
- **plugins**: a few small Paper plugins we wrote for ourselves (whitelist sync, AFK kick)
- **discord-bot**: posts server status and player count to our Discord

## Joining

The server is whitelist-only and we're not taking new players right now.

These are mostly personal projects, but feel free to fork anything useful. Issues and PRs are welcome, though replies may be slow.
